# Геометрия Киселёва — сайт открытого издания

Версия сайта 6. Единая библиотека восьми книг «Элементарной геометрии» по 23-му изданию 1914 года. Первая опубликованная книга — стереометрия, Книга I «Прямые и плоскости», v1.0.1. [Открыть сайт](https://rockyversus.github.io/kiselev/)

## Открыть локально

Распакуйте архив в отдельную папку и откройте `index.html`. Все изображения, стили, скрипты и PDF находятся в архиве. Для чтения, скачивания PDF и просмотра страницы подключение к интернету не требуется; внешние ссылки на источники и GitHub требуют сети.

## Файлы

- `index.html` — главная страница, каталог, карточка текущего выпуска и информационные разделы.
- `styles.css` — адаптивная вёрстка в согласованной цветовой и типографической системе.
- `script.js` — мобильное меню и увеличение реальных страниц; каталог и основные ссылки работают без JavaScript.
- `assets/` — подлинные страницы оригинала и опубликованного выпуска, PDF для читателей.
- `assets/social-preview.jpg` — карточка ссылки на сайт с теми же страницами для социальных сетей.
- `sitemap.xml` — адреса сайта и опубликованных PDF для поисковых систем.
- `.nojekyll` — отключение Jekyll на GitHub Pages.

## Публикация через GitHub Pages

Репозиторий сайта — `rockyversus/kiselev`. GitHub Pages публикует файлы из корня ветки `main` (`Settings → Pages → Deploy from a branch → main → /(root)`). Файл `.nojekyll` позволяет разместить готовый HTML напрямую. После обновления ветки проверьте главную страницу и PDF по публичному адресу. [Настройки Pages](https://github.com/rockyversus/kiselev/settings/pages)

Прежний публичный адрес перенаправляется на новый из [репозитория персонального сайта](https://github.com/rockyversus/rockyversus.github.io).

## Добавление следующих книг

В `index.html` раздел `#library` содержит две группы: планиметрия (5 книг) и стереометрия (3 книги). После публикации очередной книги:

1. Поместить проверенный PDF в `assets/` и добавить карточку с названием, обложкой, точной версией, датой, числом страниц и ссылкой на релиз.
2. У соответствующей строки каталога изменить статус на «Доступна», добавить класс `book-ready` и ссылку на карточку. Обновить число опубликованных книг, значения шкалы и количество книг в каждой группе. Не считать незавершённые пилоты полными книгами.
3. При необходимости обновить первый экран и примеры. Оставлять старые версии PDF доступными через релизы GitHub; не подменять файл ранее опубликованного релиза.
4. Добавить адрес нового PDF в `sitemap.xml` и обновить сведения об источниках. Проверить сайт на широком и узком экранах, а затем опубликовать согласованное изменение.

Весь каталог статический, поэтому обновление не требует базы данных, API или JavaScript-фреймворка. Отдельный репозиторий для каждой книги не нужен.
